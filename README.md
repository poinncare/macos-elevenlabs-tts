# TTS для macOS

Небольшое приложение для озвучивания выделенного текста через ElevenLabs. Интерфейс написан на Objective-C и AppKit; речь не генерируется локально.

## Возможности

- Выпадающий список голосов из аккаунта ElevenLabs.
- Короткий русскоязычный образец автоматически звучит при смене голоса.
- Глобальное сочетание Control + V для озвучивания выделенного текста.
- Озвучивание текста из буфера, в том числе со снимков экрана.
- Остановка текущего воспроизведения.
- API-ключ хранится в Связке ключей macOS. В репозитории ключа нет.

Текст отправляется на `api.elevenlabs.io` для синтеза. Аудио проигрывается из памяти. Использование API расходует лимит аккаунта ElevenLabs.

## Требования

- macOS 14 или новее.
- Xcode Command Line Tools (`xcode-select --install`).
- API-ключ ElevenLabs с доступом к Text to Speech.

## Сборка и запуск

```sh
bash build.sh
open TTS.app
```

Перед первым запуском сохраните ключ в Связке ключей как пароль общего типа: **Сервис** — `just-aloud-api-key`, **Учётная запись** — имя вашей учётной записи macOS, **Пароль** — ваш ElevenLabs API-ключ. Приложение получает ключ напрямую из Связки ключей; не вставляйте его в исходники или Git.

Дважды щёлкните по `TTS.app`, чтобы открыть окно выбора голоса. При выборе голоса прозвучит короткая фраза по-русски.

1. Нажмите **Разрешить чтение выделенного текста…** в окне TTS и включите TTS в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
2. Выделите текст в любом приложении и нажмите **Control + V**. TTS сначала читает выделение через API универсального доступа. Если приложение его не отдаёт, TTS отправляет в него **Command + C** и после чтения восстанавливает содержимое буфера. Если вы ранее назначали Control + V для службы **Озвучить через TTS**, снимите старое назначение.
3. Если выделение недоступно, нажмите **Control + Shift + Command + 4** и обведите нужный текст. Откройте TTS и нажмите **Озвучить из буфера**. Текст распознаётся на Mac, затем отправляется в ElevenLabs. Кнопка также читает обычный текст, который вы скопировали вручную.

Защищённые поля и приложения, которые блокируют копирование или снимки экрана, могут ограничивать эти способы. Пункт **Озвучить через TTS** также доступен в меню **Службы** приложений, которые его поддерживают.

Голоса загружаются из вашего аккаунта. Модель Eleven Multilingual v2 поддерживает русский язык. Ограничение одного запроса — 10 000 символов.

## Автозапуск при входе в macOS

Скопируйте собранное приложение в `/Applications/TTS.app`, затем установите LaunchAgent:

```sh
mkdir -p ~/Library/LaunchAgents
cp LaunchAgent.plist ~/Library/LaunchAgents/local.simple-elevenlabs-tts.plist
launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/local.simple-elevenlabs-tts.plist
```

Отключить автозапуск можно в **Системные настройки → Основные → Объекты входа** или командой:

```sh
launchctl bootout "gui/$(id -u)" ~/Library/LaunchAgents/local.simple-elevenlabs-tts.plist
```
